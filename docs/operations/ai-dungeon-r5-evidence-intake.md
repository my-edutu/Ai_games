# AI Dungeon R5 Evidence Intake

R5 promotion accepts only primary evidence bound to the exact deployed candidate SHA/config/content identity. Required classes are: credentialed current provider tests, production-reference capacity/output captures, independent exact-candidate review, witnessed recovery/rollback drill, real continuous 72-hour candidate endurance, and guarded seven-day canary.

Each artifact must identify environment, candidate SHA, configuration/content versions, start/end wall-clock times where applicable, operator/reviewer identity or independent witness reference, pass criteria and any incident/deviation. Compressed simulation, fixture providers, synthetic elapsed time and self-authored attestations do not satisfy external gates.

The final readiness assessor may return `PASS / R5 / productionReady:true` only when every class is complete and there are zero open P0/P1 findings.
