## Product

Autonomous Snake is a deterministic, always-on livestream game that continuously starts, plays, progresses, resolves legitimate wins/losses/stagnation, presents result/replay/intermission, and begins a new run without operator input. It supports validated procedural boards, layered survival AI, premium broadcast presentation, safe viewer influence, Chat vs AI pressure and automatic technical recovery.
