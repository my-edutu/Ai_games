# AI Maze Escape Rollback Matrix

## Rule

Rollback preserves truth before continuity. Never load incompatible evidence, move the hidden exit, rewrite a result, erase an audience acknowledgement, or call a technical interruption a fair loss. When compatibility is not proven, use a safe scene, quarantine the current run, and begin a declared fresh run.

| Change class | Stop/rollback trigger | Rollback action | Compatibility and evidence |
|---|---|---|---|
| Source / deterministic rules | Replay mismatch, invalid action ordering, hidden-information leak, unsolvable state | Roll back to the exact prior source/deployment; fence current writer | Exact source and deterministic versions; snapshot/event compatibility; final checksum; fresh run if incompatible |
| Configuration | Invalid budget, unfair timer/visibility/threat pressure, capacity breach | Restore frozen prior config | Old/new config hashes, validator pass, operator audit, canary clock reset |
| Procedural content | Unsolvable maze, key-after-lock dependency, unsafe spawn/response window | Disable pack and restore prior content | Content hashes, solver/validator evidence, affected seed list, fresh-run boundary |
| Assets / presentation | Private/hidden truth leak, unreadable mobile output, black/frozen output, unlicensed asset | Safe scene; restore prior asset bundle or renderer | Asset hash/licence, desktop/mobile capture, output-health verification; authority unchanged |
| AI policy | Suicidal/illegal movement, loop without recovery, budget overrun | Restore prior policy/deterministic version | Benchmark corpus, decision budgets, action/replay checksum; fresh run if policy state incompatible |
| Audience effect catalogue | Unsolvable mutation, unavoidable capture, duplicate effect, guaranteed result | Disable interactions/effect and restore prior catalogue | Candidate validation, idempotency/reversal audit, record-category boundary |
| Provider adapter | Authentication, privacy, duplicate, reversal, reconnect, or policy failure | Disable affected provider and restore prior adapter | Adapter version, credential rotation/revocation, provider evidence, no authority changes while disabled |
| Persistence / schema | Sequence gap, corrupt snapshot/index, failed reconstruction | Stop new authoritative commands; restore prior compatible store/schema | Event/snapshot versions, migration evidence, older-snapshot fallback, replay checksum |
| Deployment / infrastructure | Health regression, resource growth, capture/encoder failure, crash loop | Roll back exact image/deployment set | Image digest, region/host identity, lease fencing, health and output captures |
| Feature flags | Unsafe Chat vs AI/public text/quality behavior | Restore frozen prior flags | Flag snapshot/hash, operator audit, effect expiry and scene verification |

## Rollback sequence

1. Announce incident and exact candidate identity.
2. Activate the safe scene when public truth may be affected.
3. Disable interactions/public text as required.
4. Fence the writer before authority replacement or restore.
5. Preserve journals, snapshots, checksums, captures, metrics, and provider evidence.
6. Deploy the exact approved rollback identity.
7. Restore only compatible evidence; otherwise quarantine and start a fresh declared run.
8. Verify authoritative checksum, lease generation, provider state, scene/HUD, frames, captions/audio, and record eligibility.
9. Record the rollback decision, witness, evidence digest, and follow-up phase.

Any material rollback candidate change re-enters its owning phase and invalidates affected capacity, endurance, provider, drill, canary, and independent-review evidence.
