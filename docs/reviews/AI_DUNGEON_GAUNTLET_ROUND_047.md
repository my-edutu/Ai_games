## Why this increment was chosen

Round 46 identified a concrete unresolved lifecycle edge: a WebGL restore begun before first healthy startup could cross the generic startup deadline, overwriting a truthful graphics-recovery state with a misleading module failure. Previous real Chromium traces also contained roughly thirteen-second main-thread spectator freezes; there was no bounded, frame-delivery percentile evidence to measure them. Improving reliability truth and adding live browser evidence are higher-priority, testable work than speculative unmeasured asset changes.

## Separate critical review

**Specification compliance:** The fix reads browser diagnostics and immutable public state. It changes no fixed-step simulation, AI, combat, RNG draw, grid, collision, saves, replay/versioning, payment or audience state. The frame sampler uses bounded memory and is reset when the document is hidden. Errors remain surfaced; context loss does not become a game loss. Rollback is limited to the two implementation commits and their tests.

**Harsh visual/engineering review:** Real Round46–Round47 WebGL captures at matching layout/seed are near-identical in artistic terms. Tall dark rectangular masonry, visually simple overlapping hero/enemy models, strong cyan spots and weak contact animation still fall well below authentic Diablo IV, No Rest for the Wicked and Path of Exile 2. No claims of better art, frame smoothness, reference parity or production readiness. RequestAnimationFrame delivery intervals include event-loop scheduling/CPU effects and **are NOT GPU timestamp/p95/p99 metrics**. There is no 30–60-minute soak, real hardware context-loss recovery drill, independently judged blinded reference A/B or independent artistic critic. The connected coding-worker tunnel was unavailable; no builder/critic subagents or ultracode execution can be claimed.

**Next blocker:** collect real live output freshness over an extended constrained-hardware soak, validate the dedicated-browser evidence file and its p50/p95/p99/worst frame intervals and restore hardware WebGL, then create materially better original hero/enemy anatomy and weapon-contact motion while reducing rectangular architecture. Do not merge PR #49.
