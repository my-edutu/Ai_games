## Production change

Within the accepted near-fruit range, approaching and releasing use exponential easing with the existing clamped presentation delta. It returns to neutral when fruit disappears or moves behind/beyond the head; the real original chewing pose retains priority. Danger >=0.6 suppresses the anticipation, maintaining the existing visual danger message. Under reduced motion the original neutral/chewing jaw is static; public restarts and positional discontinuities snap the anticipation state instead of interpolating through a portal. Empty/recovery paths reset the state.
