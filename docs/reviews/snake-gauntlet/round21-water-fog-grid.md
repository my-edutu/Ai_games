## Small independent slice and code

The Round20 64×64 lake geometry had **8,192 triangles / 4,225 vertices** to interpolate distance fog, even across distant water beyond the camera's visible fog-transition zone. Now `createFogAwareWaterPlane` preserves the existing water size (512 units minimum), exact eight-unit near-field samples across the playable garden and ±176-unit central radius for ordinary boards, with one long perimeter strip on each side where the fog is already saturated. **46×46 quads = 4,232 triangles / 2,209 vertices** on ordinary 512-unit boards: **3,960 fewer water triangles (48.34%) and 2,016 fewer vertices (47.72%)**. Three's plane indices, face normals and world-space position-derived UV remain, so texture frequency/animation are not stretched. The precomposed opaque RGB texture, one fragment lookup, vertex fog, foam/falls, full horizon, all hazards/portals/food, silhouette, depth and 3D scene remain. No sim/AI/scoring/public snapshot/caption/quiet/reduced-motion/fallback/recovery/authority or acceptance threshold changes.

New `tests/phase3/snake-water-adaptive-grid.test.cjs` checks four board sizes, exact dense step spacing, symmetric distant coarse strips, resource and draw-object stability, horizon, shader UV, reduced motion and disposal. Existing `snake-water-fog-vertex` test now verifies adaptive rather than obsolete uniform geometry, while **retaining the pre-existing max 0.013 fog interpolation bound**. Source was built in an isolated exact-sha GitHub tree; all branch writes were compare-and-swap, non-force, with source blob checks. The local shared-workspace agent tunnel remained offline; only approved GitHub CI was used for execution.
