## Independently judgeable production slice
The existing overview *static-world render target* has independently selected `samples: cacheSamples` (typically 4 on CI), even while the main WebGL canvas also requests `antialias:true` and renders the flowing water, snake and live hazards every frame. This candidate requests `antialias:false` **only for the final canvas**, leaving the original multisampled scenery target, authored geometry, materials, textures, shaders, lighting, particles and all world updates untouched. It requests no new resources and changes no source for AI, scoring, simulation/replay, public snapshot, portal discontinuity, cues/captions/HUD, reduced motion, fallback or recovery. It can make dynamic fine edges jaggier; that is a real quality risk, not a free speedup.
