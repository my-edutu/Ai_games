**Implementation:** Before any frames, the original 3D face hierarchy is traversed once. Its repeated detailed Standard materials map to preallocated lightweight MeshLambert diffuse equivalents, retaining authored base color, existing map when present, vertex-colored cheek-to-chin gradient, sidedness, opacity and depth behavior. No body/head geometry, anatomy, gaze, eating, glints, camera, foliage, water, authored textures or on-screen UX are removed. The old original Standard meshes return **exactly** in high-detail camera mode, including PBR bump/roughness maps, so the cinematic close-up is unaffected. Small unlit eye catchlights stay unlit. Materials are pooled by original identity, switched only when the existing detail view changes, owned by the original dispose Set. **No new textures, geometry, draw calls, GPU passes or frame-time allocations**; finite preallocated materials increase the static material inventory. No authored facial asset or material is sourced from Snake Pass.

**Safety:** Rendering consumes the immutable public snapshot. Grid authority, seeded random AI, score, portal-separated body paths, visible hazards, food, goal, captions, mobile/portrait layout, reduced-motion, mute, GL failure/recovery, GPU backpressure and resource-cap acceptance are unchanged. The presentation-only materials cannot alter replay. Original eyes, jaws, skin, expression and geometry remain present. Rollback: revert this single source change and its new two regressions. PR remains draft; no merge/deploy.

**Regression protocol:** New `tests/phase3/snake-overview-face-lod.test.cjs` checks nine actual facial mesh types, exact reuse of original detailed PBR on view switch, Lambert overview with same pigment/vertex tint/sidedness/occlusion, original glints, portal fragments and 140 reduced-motion/animation cycles with bounded resources. New `tests/browser/snake-face-diffuse-lod.spec.cjs` reconstructs the exact previous serpent blob by SHA1, runs genuine Chromium/SwiftShader WebGL with an unchanged frozen public replay in 960×640 overview *and* detail, saves full-page PNGs and checks GL errors and object/texture/buffer budgets. It requires a genuine overview-image change but identical detailed-camera pixels. This browser fixture is **not live FPS, display-present FPS, or independent visual criticism**.
