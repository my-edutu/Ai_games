# Round 29 — rear-ruins close-camera foreground occlusion guard (2026-10-31)

**Quality bar:** Original Snake Pass gameplay/character/world captures; ASTRO BOT secondary. This is a narrow, independently measurable presentation-readability issue, not a commercial visual victory.

**Root cause and scope:** Real Round24 motion occasionally lost the close-up hero behind scenery. The old frontal three-quarter detail camera was blind to the existing pillars, arched masonry and foreground tree masses near the northern boundary. The public head and food must never be moved to fake a cleaner shot.

**Production change:** Register a finite set of camera-only proxies at the same coordinates that construct actual world columns, arch stones, tree trunks/crowns and front rock. The detail camera first retains its existing food sightline correction, then tests a small, ordered set of alternate azimuth/elevation angles only when that exact eye-to-head line crosses foreground mass. It keeps head targeting and face distance unchanged; no new geometry, shaders, textures, draw calls, other-camera changes, gameplay state mutations or network dependencies. Existing camera offset easing protects against hard cuts. The scene's unchanged geometry stays authoritative for occlusion.

**RED / GREEN:** A new source-independent geometry probe tests an actual near-pillar sightline and first failed on the original camera (no guard, ~0.4 normalized foreground overlap). After implementation the isolated local camera suite passed **3/3**, reducing that fixture's overlap to **zero** while preserving center, zoom, portrait, food and safe-mode invariants. Additional Three.js world resource/dimension test and a same-frame real WebGL A/B browser stress capture are included in this commit; their CI outcomes are **pending**, not reported as passes.

**Visual criticism:** This protects close-up readability in a known difficult part of the diorama. A real WebGL still pair (`character-rear-arch-without-synthetic.png`, `character-rear-arch-with-synthetic.png`) from a clearly labelled **synthetic public-frame camera fixture** is required before accepting the appearance. This local test is not live GPU cadence, measured display FPS, sustained hardware performance or proof of whole-game polish. Official Snake Pass remains stronger on facial anatomy, landscaping, lighting, articulated contact and smooth animation. Independent critic unavailable while shared worker tunnel is offline; no fabricated sign-off.

**Safety and rollback:** Deterministic simulation, AI, scoring, public snapshot schema, portal fragments, hazard/food cues, captions, reduced-motion, recovery, safety overview, static-cache and the unchanged **≥17 actual desktop submissions** gate are retained. Revert the camera+world+renderer patch if snapshots or real-browser coverage regress. PR remains **draft, unmerged, undeployed**. Before/after actual captures, broad catalogue CI, real-device present cadence, R5 and independent still/motion reviews remain open until verified.
