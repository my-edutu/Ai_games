## One production adjustment

Only when the existing R53 first-canvas rule actually reduces an oversized native color raster, select the **already-existing 1024×1024 low-tier shadow map before first scene submission**. This is a **75% reduction in initial shadow texels**, not a measured 75% time saving; 1024 was already the subsequent adaptive resolution. Ordinary native and portrait/phone retina views keep 2048. No additional GPU objects, queues, passes, private state, hidden scene/water, removed character parts, altered gameplay authority, or changed cadence thresholds. The static environment, live hazard/portals, 3D serpent, water, captions, reduced motion, recovery and public snapshots remain.
