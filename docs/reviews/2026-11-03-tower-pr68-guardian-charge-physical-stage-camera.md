## Systemic visual/gameplay-fidelity problem addressed
The actual guardian charge could collapse a fixed eight-warning-arrow instance into a single overlapping heap when the guardian stood near the climber. Small unlit cones then risked reading as debug pixels rather than the true lethal direction on the cylindrical 3D stage. A portrait camera focusing on the guardian could still frame the actor while keeping the source warning lane behind opaque masonry.

The same live guardian telegraph now:
- limits the warning to the **currently observed** horizontal separation, ending before the present player;
- sizes instance count by available physical lane (one near contact; up to eight low / twelve high), using physically lit, tapered four-faced forged vanes instead of tiny washed-out triangles;
- exposes the same exterior world-space charge focus to the actual follow-camera lens, where it earns composition priority **only if both the guardian and skinned climber still pass the hard size/visibility/core checks**;
- keeps original skinned charge, combat physics, hitboxes, AI policy, projectiles, opt-in audio and minimal HUD untouched.

One bounded existing instanced draw and no added lights, shadow casters, geometry per frame, simulation events, new renderer passes or overlays. The warning disappears on invalid/finished/stale/restarted source, and reduced motion preserves a static recognizable danger shape.
