## Same transformation; what the real game now does

**Source at implementation:** [dffecaac](https://github.com/my-edutu/Ai_games/commit/dffecaacbb3375453d47b40073b4d4c9f46b6508). This continues the same physical ascent → meaningful guardian duel → HP-connected gate → source-authentic result/restart initiative. No separate micro-patch quality milestone was awarded.

The existing live second-wind guardian really blocks melee for up to 22 fixed 20Hz ticks following HP damage, but the fixed-step combat authority deliberately **opens** that shield when an authentic guardian attack windup begins. The climber previously retreated or held position through that source-observed vulnerable interval without Pulse Shot. The AI now counterattacks **only** during the live opt-in shielded guardian's observed early telegraph, when its existing melee is off cooldown, the player is grounded on validated support, facing the true enemy, vertically aligned, inside actual hit reach and able to stand without a dangerous safety correction. Present projectiles/hazards and late windup evasive jumps still take priority. No simulated damage/attack, free cooldown bypass, guessed future attack or historical tactical-v1 rewrite.

The existing original 3D guard skeleton now physically unfolds four instanced copper battens from the observed hostile windup; source charge ticks control how exposed they become. Reduced motion keeps an immediately understandable static opening. The same new actual charge edge can generate a small **opt-in** material sound: muted players rely on the animated/static world itself. The game's existing maul windup, source HP lock, cinematic camera and minimal HUD remain.

This is a connected AI + actual authoritative combat + world-space 3D + audio playable scene change, but only **source tests** and candidate video can establish if it functions and is enjoyable in practice.
