## Real game and systemic experience gap
Prior game-world work added an original moving-platform gear/piston stage, source-driven rider counterbalance, a 16-member loaded carriage spring, selected-platform architecture, skinned enemy and climber counterplay, plus sourced guardian and result passages. An ordinary fixed-step landing still felt visually disconnected from the resulting world: a brief torus ring and camera settle, with no tangible source-owned debris/weight at the exact solid deck.

This continuation gives the **actual playable scene** a bounded physical-impact material moment linked to the *same genuine landing* as the already-existing camera weight and sound. The original climber must first be observed airborne with downward velocity, then standing with zero vertical velocity in the same running token, floor and <=8 source ticks. The landing predicate also verifies the current player's true feet overlap the top of one finite, positive-area platform in the actual immutable public snapshot, not the AI's future destination. It records source tick, occupied platform ID, world X, deck top, run and floor. Missing/singular/remote platforms, broken packets, dead characters and fake run transitions cannot earn the visible debris.

The live Three.js world now includes an original **16-instance, depth-tested 3D stone/metal contact burst**, near and above the actually contacted walkable surface, with short bounded radial displacement and lift relative to source impact strength. It belongs to the existing original shared-resource scene, not a second system or an overlay. The normal low tier shows up to 8 fragments; high tier shows up to 16; reduced motion retains only 4 small quiet glints with no outward burst. It never changes collision, physics, AI, enemy health, procedural seed, run state or replay authority; there are no new lights, shadows, sounds, HUD labels, or network data. Restart and graphics recovery clear the source event, and the instance owner shares normal scene resource disposal. On stale/source discontinuity, terminal and expired impact, draw count becomes zero.

The existing camera's authentic touchdown shift and source-earned landing audio remain integrated. The source-selected destination/guardian presentation stays top priority.
