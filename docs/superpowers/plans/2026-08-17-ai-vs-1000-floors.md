# AI vs 1,000 Floors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic autonomous tactical roguelite that can climb, fail, recover and restart across a validated 1,000-floor campaign, then add a premium livestream presentation, safe audience influence, unattended operations and evidence-gated release governance.

**Architecture:** One fixed-step simulation worker owns all authoritative state. A constructive floor generator, bounded layered AI, progression rules and influence reducer feed one ordered rules pipeline; presentation, audio, providers, persistence and operator systems consume versioned immutable contracts and never mutate gameplay directly. The implementation follows Autonomous Snake's six phase/R-level progression while using the tactical decomposition proven by AI Maze Escape.

**Tech Stack:** Node.js 22.16.0, TypeScript 5.8.3, CommonJS output, Node test runner, shared `NamedRng`, stable replay checksums, native HTTP/SSE, HTML5 Canvas, Web Audio API and Playwright 1.55.0.

## Global Constraints

- Authoritative logic uses fixed integer ticks; render delta and wall-clock time cannot affect results.
- All authoritative randomness uses named streams derived from the recorded run seed.
- No game module imports YouTube, Twitch, payment, database, OBS or operator-dashboard SDKs.
- Public presentation consumes sanitized immutable render snapshots and semantic events only.
- Optional provider, renderer, audio, telemetry or persistence failure cannot block simulation continuity when gameplay truth remains valid.
- No viewer action, payment or director event can guarantee victory, death, a record or survival.
- Every collection, queue, cache, planner search, replay buffer, audio voice and effect pool has a hard bound.
- Technical failure, invalid generated content and integrity quarantine are never recorded as legitimate gameplay losses.
- Each phase exits only after focused tests, affected regression tests, a specification review and a separate engineering/viewer-experience review contain no open P0/P1 finding.
- R5 and “production ready” language remain blocked until exact-candidate real provider, 72-hour endurance, seven-day canary, deployment and independent-review evidence exists.
