# Tower: gameplay clarity and character identity

User direction: keep building Game 3, reduce excess text during gameplay, and improve the UI, scenes, and characters. This continues the authorized 3D Gauntlet work on draft PR #58.

## Comparison bar

Compare real Tower captures with the official ASTRO BOT **Rising Heat** footage for a clearly framed protagonist, readable hostile silhouettes, an obvious next landing, and a quiet HUD that leaves the action visible. The existing review prefers the reference; this iteration does not assume parity.

## Independent work and judgement

- HUD builder: compact vitals and icon controls; put intent and secondary telemetry in optional details; keep truthful recovery notices clear of the retained scene. Preserve accessible labels and genuine upgrade/result states.
- Scene builder: compose the actual hero, immediate threat, and intended landing; reduce the Foundry wheel's dominance; preserve an overview camera and all authoritative positions.
- Cast builder: make sentinel, shooter, and guardian visibly hostile through silhouette, face, equipment, and stance; retain the climber's distinct identity and snapshot-driven poses.
- Lead: integrate recovery metadata, capture actual authoritative encounters on desktop and default-low portrait, maintain the live journal, and return independent critics' largest gaps to the builders.

Critics receive the real rendered output and the commercial reference with fresh context. A comparison is labelled source-known unless the identities can actually be concealed. Static snapshots establish appearance only; motion and successful recovery require their own evidence.

## Verification and continuation

Run focused tests for changes to recovery, target cues, pose behaviour, and camera framing, then affected browser controls/layout and real context restoration. Keep failures in the evidence record. Use one owned browser at a time on the shared renderer host. Do not infer smooth playback from advancing simulation or DOM values.

Publish cohesive changes to the existing draft branch and update `/tower/gauntlet` with captures, criticisms, and unresolved gaps. Continue from the largest remaining visual or functional gap; do not set a fixed number of rounds or mark the commercial bar won without evidence.
