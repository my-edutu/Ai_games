# Curriculum

1. Align two geospatial/time-series sources.
2. Build seasonal/weather/vegetation features.
3. Visualize missingness and spatial distributions.
4. Implement climatology/previous-season baselines.
5. Create time + spatial blocked backtests.
6. Compare boosted/regression models.
7. Add quantile intervals and evaluate coverage.
8. Stress missing satellite/weather inputs.
9. Produce map/API forecast artifact.
10. Write regional model/data cards and release review.
