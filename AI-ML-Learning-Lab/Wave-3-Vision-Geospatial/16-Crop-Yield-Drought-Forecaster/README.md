# 16 — Crop Yield & Drought Forecaster

Build a spatiotemporal system that forecasts crop yield or drought risk using weather, vegetation, soil and historical production data, with uncertainty and geographic validation.

**Primary skills:** time series, geospatial features, remote sensing, regression, probabilistic forecasting, spatial validation.

**Final deliverable:** map/API-ready forecast pipeline with calibrated uncertainty, spatial/temporal backtests and documented data limitations.
