# Phase 4 — Baseline and Evaluation Harness

Use climatology, previous-season and simple regression baselines. Backtest across seasons and hold out geographic regions.

**Build:** MAE/RMSE/R² or drought classification metrics, spatial error maps, interval coverage.

**Learn:** spatial autocorrelation, blocked validation, naive baselines.

**Exit:** evaluation prevents neighboring-region leakage from overstating performance.
