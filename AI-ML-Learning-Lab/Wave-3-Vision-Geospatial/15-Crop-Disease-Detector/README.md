# 15 — Crop Disease Detector

Build a computer-vision system that detects likely crop diseases from leaf/plant images and returns uncertainty-aware guidance for human/agronomist review.

**Primary skills:** image classification, transfer learning, augmentation, dataset shift, calibration, explainability, mobile/edge inference.

**Final deliverable:** reproducible disease-classification service/app prototype with calibrated confidence, image-quality checks, explainability, field validation and monitoring.
