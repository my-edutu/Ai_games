# Service Level Objectives

For a controlled deployment target: 99.5% successful API responses excluding invalid client requests; p95 `/v1/match` latency below 300 ms for 100 opportunities on reference hardware; 100% response traceability to model/data versions; zero learned-model overrides of deterministic eligibility; rollback mechanism tested before release.

These are target SLOs for the project. They are not claims of observed production performance until real telemetry exists.
