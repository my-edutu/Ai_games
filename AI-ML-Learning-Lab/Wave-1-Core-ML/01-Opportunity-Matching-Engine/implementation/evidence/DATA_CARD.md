# Data Card

The development dataset is deterministic synthetic data generated by `opportunity_matching.synthetic`. It covers multiple skills, interests, opportunity types and locations while keeping all generated candidates eligible so ranking quality can be isolated from eligibility behavior.

This dataset contains no real personal data. It must not be represented as population evidence. Before live deployment, replace or supplement it with consented, governed interaction/outcome data and repeat leakage, fairness, calibration and temporal validation checks.
