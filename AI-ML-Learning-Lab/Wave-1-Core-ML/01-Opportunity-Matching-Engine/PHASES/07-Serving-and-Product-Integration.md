# Phase 7 — Serving and Product Integration

Expose matching through a stable API and design response payloads around useful user explanations rather than raw scores.

**Build:** FastAPI service, typed request/response contracts, eligibility reasons, top-K results, version metadata, latency/load tests, integration examples.

**Learn:** model serving, serialization, idempotency, batching, caching, API versioning.

**Exit:** a client can request matches reliably and trace each response to model/data versions.
