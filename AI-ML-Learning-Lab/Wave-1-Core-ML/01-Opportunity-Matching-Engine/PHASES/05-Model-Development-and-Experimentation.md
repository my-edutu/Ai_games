# Phase 5 — Model Development and Experimentation

Compare justified approaches: engineered similarity, gradient-boosted ranking, two-stage retrieval/reranking, or semantic embeddings. Change one major variable per experiment.

**Build:** experiment registry, hyperparameter/config files, model comparison table, error examples, reproducible training command.

**Learn:** learning-to-rank, pairwise/listwise losses, embeddings, cross-validation limitations, ablation studies.

**Exit:** selected model beats the baseline on agreed metrics and the gain survives cohort and temporal checks.
