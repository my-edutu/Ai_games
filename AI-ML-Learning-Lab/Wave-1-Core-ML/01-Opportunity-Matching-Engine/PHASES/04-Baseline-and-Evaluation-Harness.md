# Phase 4 — Baseline and Evaluation Harness

Start with understandable rules: hard eligibility filtering plus weighted profile similarity. Establish a baseline before complex models.

**Build:** deterministic baseline ranker; Precision@K, Recall@K, MAP/NDCG where appropriate; coverage/diversity measures; evaluation fixtures.

**Learn:** ranking metrics, offline evaluation, baselines, confidence intervals, metric gaming.

**Exit:** baseline results are reproducible and the team knows which metric improvements would actually matter to users.
