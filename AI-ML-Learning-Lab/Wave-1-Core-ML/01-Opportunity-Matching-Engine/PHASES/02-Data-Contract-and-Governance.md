# Phase 2 — Data Contract and Governance

Design schemas for user profiles, opportunity requirements, outcomes, interactions, and labels. Mark fields as required/optional, mutable/immutable, sensitive/non-sensitive, and define provenance and retention.

**Build:** versioned schema, sample records, label policy, consent/privacy notes, leakage checklist, data validation tests.

**Learn:** train/serve skew, leakage, missingness, sampling bias, personally identifiable information, data lineage.

**Exit:** invalid records fail deterministically and every feature has an owner, source, rationale, and permitted use.
