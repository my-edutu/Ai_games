# Curriculum

1. Write an acceptable-use and prohibited-use policy.
2. Construct point-in-time features.
3. Demonstrate a temporal leakage bug.
4. Train/calibrate a logistic baseline.
5. Compare boosted model using time split.
6. Evaluate subgroup calibration and false positives.
7. Build cold-start/abstention behavior.
8. Add audit and correction workflow.
9. Run a simulated shadow pilot and inspect action disparities.
10. Present a model risk review arguing whether deployment is justified.
