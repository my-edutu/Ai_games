# 09 — Worker Reliability Predictor

Build a carefully governed model for operational reliability signals such as attendance, job completion or cancellation risk—without turning a prediction into an unchallengeable worker score.

**Primary skills:** classification, temporal features, calibration, fairness, causal pitfalls, responsible decision support.

**Final deliverable:** calibrated risk-support system with strong human review, appeals/correction path, bias monitoring and restricted use.
