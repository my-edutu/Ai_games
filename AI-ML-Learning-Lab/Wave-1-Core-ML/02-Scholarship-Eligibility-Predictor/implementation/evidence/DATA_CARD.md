# Data Card
owner: Data/ML Platform
status: representative benchmark only

The bundled benchmark uses deterministic synthetic/representative applicant records with GPA, financial need, leadership, community service, essay, experience, application date, region, and a noisy suitability label. It is intended for engineering validation, leakage checks, calibration tests, and cohort evaluation only.

Every snapshot is canonicalized and SHA-256 hashed. Real applicant data requires consent, minimization, retention limits, access controls, provenance, and jurisdiction-specific privacy review before use.
