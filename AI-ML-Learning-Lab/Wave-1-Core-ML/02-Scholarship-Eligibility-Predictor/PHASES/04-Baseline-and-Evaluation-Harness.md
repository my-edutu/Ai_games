# Phase 4 — Baseline and Evaluation Harness

Implement exact rule evaluation first. For the predictive layer, start with logistic regression or another transparent baseline.

**Build:** rule-engine tests, confusion matrix, ROC/PR analysis, Brier score/calibration curve, cohort breakdown.

**Learn:** precision/recall, PR-AUC, calibration, thresholding.

**Exit:** baseline behavior is trusted on hand-authored edge cases.
