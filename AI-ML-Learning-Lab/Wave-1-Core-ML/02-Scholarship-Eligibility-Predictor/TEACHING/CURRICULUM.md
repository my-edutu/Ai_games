# Curriculum

1. Encode five scholarship policies as executable rules.
2. Create boundary tests for age, GPA, nationality and deadlines.
3. Train a logistic baseline and interpret coefficients cautiously.
4. Plot precision-recall and calibration curves.
5. Compare threshold choices under asymmetric error costs.
6. Deliberately introduce leakage, detect it, then remove it.
7. Audit subgroup performance.
8. Build reason codes tied to exact policy clauses.
9. Serve both eligibility and calibrated suitability safely.
10. Write a release review explaining where automation must stop.
