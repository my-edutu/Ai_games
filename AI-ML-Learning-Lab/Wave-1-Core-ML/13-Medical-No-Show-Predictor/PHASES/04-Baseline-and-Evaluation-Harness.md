# Phase 4 — Baseline and Evaluation Harness

Start with simple historical-rate/logistic baselines and evaluate calibration, PR-AUC and intervention-relevant recall at capacity limits.

**Build:** baseline, calibration, decision-curve/utility scenario, subgroup metrics.

**Learn:** calibration, capacity-constrained thresholds, clinical utility concepts.

**Exit:** baseline utility is quantified rather than inferred from accuracy.
