# Curriculum

1. Map prediction to supportive interventions.
2. Build a point-in-time appointment dataset.
3. Train/calibrate a transparent baseline.
4. Evaluate PR-AUC and capacity-limited recall.
5. Compare boosted model and ablations.
6. Audit subgroup calibration/errors.
7. Stress missing/new-patient scenarios.
8. Implement approved-action API and audit log.
9. Design a pilot measuring both benefit and burden.
10. Produce a healthcare ML risk/release review.
