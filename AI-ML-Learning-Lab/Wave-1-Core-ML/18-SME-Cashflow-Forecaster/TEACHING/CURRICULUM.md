# Curriculum

1. Aggregate raw transactions into a clean daily/weekly series.
2. Plot trend/seasonality and diagnose leakage risk.
3. Implement naive and seasonal-naive baselines.
4. Build rolling-origin backtesting.
5. Compare statistical and boosted models.
6. Create quantile/prediction intervals and measure coverage.
7. Stress a structural break and missing feed.
8. Serve forecast + interval + scenario API.
9. Reconcile prior forecasts with actuals in monitoring.
10. Write a production forecast review emphasizing uncertainty and failure modes.
