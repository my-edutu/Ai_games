# 18 — SME Cashflow Forecaster

Build probabilistic short-term cash-in, cash-out and net cash-balance forecasts for small businesses, with uncertainty ranges and scenario analysis.

**Primary skills:** time-series forecasting, feature engineering, backtesting, probabilistic forecasts, hierarchical/seasonal patterns, monitoring.

**Final deliverable:** reproducible forecasting service/dashboard that exposes uncertainty and never presents forecasts as guaranteed financial outcomes.

Phases 1–10 are implemented and verified as a controlled-deployment candidate. See `implementation/` and `PHASE_STATUS.md`. Broad production remains gated on genuine SME shadow validation.
