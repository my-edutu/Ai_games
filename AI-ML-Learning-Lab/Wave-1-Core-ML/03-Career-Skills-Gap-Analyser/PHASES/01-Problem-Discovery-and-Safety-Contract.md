# Phase 1 — Problem Discovery and Safety Contract

Define “skill,” evidence strength, proficiency, target role, and gap. Avoid inferring competence from demographic proxies or treating absent resume text as proof a skill is absent.

**Build:** ontology scope, user journey, output contract, safety/non-goals, metrics.

**Learn:** taxonomy/ontology basics, multi-label problems, uncertainty.

**Exit:** the system distinguishes observed evidence, inferred evidence, and unknown.
