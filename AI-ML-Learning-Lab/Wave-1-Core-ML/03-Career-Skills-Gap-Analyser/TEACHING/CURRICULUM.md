# Curriculum

1. Design a 50-skill mini taxonomy with aliases.
2. Build dictionary extraction and a golden test set.
3. Measure micro/macro precision, recall and F1.
4. Compare bag-of-words and embeddings on role similarity.
5. Create a multi-label extraction experiment.
6. Analyze ambiguous skills and false gaps.
7. Add source-highlight evidence and confidence.
8. Test sparse/non-standard profiles.
9. Build API and correction workflow.
10. Produce a model/taxonomy governance review.
