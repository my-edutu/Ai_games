# 03 — Career Skills Gap Analyser

Build a system that compares a person's demonstrated skills with target-role requirements and produces evidence-based skill gaps and learning priorities.

**Primary skills:** taxonomy design, multi-label classification, embeddings, similarity, recommendation, uncertainty, evaluation.

**Final deliverable:** explainable role-skill gap service with provenance for extracted skills and prioritized learning recommendations.

## Implementation status
Phases 1–10 are implemented and verified as a controlled-deployment candidate. See `implementation/` for source/tests/evidence and `PHASE_STATUS.md` for phase-by-phase gates. Genuine real-user pilot evidence remains required before broad production-impact claims.
