# Curriculum

1. Select 2–3 languages and define labels with examples.
2. Build an annotation/adjudication guide.
3. Analyze Unicode/tokenization and code-switching.
4. Train a simple multilingual baseline.
5. Fine-tune a multilingual transformer.
6. Report metrics per language/category.
7. Build dialect/slang/context challenge set.
8. Add uncertainty + reviewer escalation.
9. Simulate active-learning cycle with reviewer corrections.
10. Write per-language model-card sections and release decision.
