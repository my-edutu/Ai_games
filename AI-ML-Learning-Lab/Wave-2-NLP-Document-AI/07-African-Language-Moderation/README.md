# 07 — African-Language Moderation

Build multilingual content moderation for selected African languages and code-switched text with locally grounded label definitions and strong human escalation.

**Primary skills:** multilingual NLP, transfer learning, tokenization, code-switching, annotation, fairness, calibration, active learning.

**Final deliverable:** moderation classifier/service for explicitly supported languages, with per-language metrics, uncertainty, human review and documented unsupported cases.

## Implementation status
Phases 1–10 are implemented and verified as a controlled-deployment engineering candidate. Supported engineering scope is `sw` and `pcm`; broad production remains blocked pending native-speaker validation and real multilingual shadow evaluation.
