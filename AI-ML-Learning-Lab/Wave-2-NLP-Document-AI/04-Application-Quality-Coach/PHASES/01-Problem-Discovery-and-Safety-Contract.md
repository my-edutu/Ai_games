# Phase 1 — Problem Discovery and Safety Contract

Define the application types, rubric dimensions and boundaries. The system may coach but must not fabricate experience, credentials, awards or personal facts.

**Build:** user journeys, rubric, non-goals, unsafe-output examples, metric tree.

**Learn:** rubric design, generative-vs-evaluative NLP, hallucination risk.

**Exit:** every recommendation can be traced to a rubric or the applicant's own text.
