# 04 — Application Quality Coach

Build an NLP assistant that reviews scholarship/job/fellowship application text for clarity, completeness, evidence, relevance and structure without inventing achievements or impersonating the applicant.

**Primary skills:** NLP, embeddings, rubric-based evaluation, retrieval, LLM evaluation, guardrails, human-centered feedback.

**Final deliverable:** an explainable coaching API that scores against explicit rubrics, cites evidence from the user's text, suggests improvements, and clearly separates critique from rewriting.
