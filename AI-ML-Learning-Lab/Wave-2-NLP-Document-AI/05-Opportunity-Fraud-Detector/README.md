# 05 — Opportunity Fraud Detector

Build a system that flags potentially fraudulent scholarships, jobs, grants and fellowships using text, metadata, URLs, publisher history and anomaly signals. Output risk evidence for human review rather than declaring criminality.

**Primary skills:** imbalanced classification, NLP, anomaly detection, URL/domain features, calibration, explainability, adversarial robustness.

**Final deliverable:** risk-scoring pipeline/API with evidence, uncertainty, reviewer workflow and continuously updated threat evaluation.

Phases 1–10 are implemented and verified as a controlled-deployment candidate. See `implementation/` and `PHASE_STATUS.md`. Broad production remains gated on live reviewer shadow validation.
