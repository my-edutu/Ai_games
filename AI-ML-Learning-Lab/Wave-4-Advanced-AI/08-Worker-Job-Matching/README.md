# 08 — Worker–Job Matching

Build a two-sided matching/ranking system for workers and service jobs using eligibility, skills, distance/availability, preferences and quality signals while avoiding discriminatory proxies.

**Primary skills:** retrieval/ranking, constraints, geospatial features, recommender systems, fairness, marketplace metrics.

**Final deliverable:** explainable top-K matcher with hard constraints, balanced marketplace objectives, API and monitoring.
