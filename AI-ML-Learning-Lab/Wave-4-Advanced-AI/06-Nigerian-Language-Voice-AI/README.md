# 06 — Nigerian-Language Voice AI

Build speech recognition and voice-interaction capabilities for selected Nigerian languages and code-switched speech, with explicit supported-language scope and human fallback.

**Primary skills:** ASR, audio preprocessing, multilingual speech, transfer learning, WER/CER, code-switching, latency, privacy.

**Final deliverable:** reproducible speech-to-text/voice service for chosen languages with per-language metrics, confidence, unsupported-language handling and deployment monitoring.
