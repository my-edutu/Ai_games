# Curriculum

1. Inspect waveforms/spectrograms and audio metadata.
2. Create speaker-disjoint train/test split.
3. Evaluate multilingual ASR baseline with WER/CER.
4. Fine-tune on one selected language.
5. Add balanced sampling/augmentation.
6. Evaluate dialect, noise, device and code-switch subsets.
7. Build confidence/fallback behavior.
8. Implement streaming or batch API and benchmark latency.
9. Pilot with native speakers and corrections.
10. Produce per-language model card and deployment review.
