# 20 — AI Employee Simulation Evaluator

Build an evaluation system for realistic work simulations: ingest participant decisions and artifacts, score them against transparent competency rubrics, check cross-artifact consistency, model stakeholder consequences and generate evidence-backed coaching.

**Primary skills:** structured evaluation, NLP/LLMs, rubric engineering, retrieval, causal caution, multi-artifact reasoning, agent/simulation evaluation, calibration.

**Final deliverable:** auditable simulation-evaluation engine with rubric scores, evidence citations, confidence, cross-artifact coherence checks, evaluator agreement and human review.
