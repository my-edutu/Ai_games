# 11 — Clinical Triage Decision Support

Build a high-stakes clinical triage support prototype that helps trained professionals prioritize review using validated inputs and explicit uncertainty. It is not autonomous diagnosis or treatment.

**Primary skills:** calibrated classification, missing data, uncertainty, clinical evaluation, safety engineering, human factors, governance.

**Final deliverable:** clinician-facing decision-support prototype with strict human oversight, auditability, external validation plan and deployment gate requiring genuine clinical governance.
