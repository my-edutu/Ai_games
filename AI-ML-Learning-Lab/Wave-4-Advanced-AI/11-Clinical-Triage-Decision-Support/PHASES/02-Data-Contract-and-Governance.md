# Phase 2 — Data Contract and Governance

Define only clinically justified variables, timestamps, outcomes, missingness, site/patient grouping and data access/privacy constraints.

**Build:** data dictionary, point-in-time rules, label adjudication, site/patient split policy, governance review.

**Learn:** clinical labels, PHI, site effects, missing-not-at-random.

**Exit:** every variable and label has clinical meaning/provenance.
