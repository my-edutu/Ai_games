# Production Readiness

R1 requires deterministic headless rules and verified restore. R2 adds representative AI/content/balance and broadcast evidence. R3 adds safe provider-neutral interaction. R4 adds durable authority, fencing, recovery, supervision, bounded resources, alerts, runbooks and chaos evidence. R5 requires the frozen exact candidate to pass every software and external gate.

Green CI does not establish R5. Production ready additionally requires current credentialed YouTube/Twitch evidence, production-reference capacity and audiovisual evidence, external security/privacy/moderation/accessibility/licence/supply-chain attestations, independently witnessed drills, a real 72-hour endurance run, a real seven-day canary and independent signed exact-candidate review. Missing evidence returns `BLOCKED_EXTERNAL` and `productionReady=false`.
