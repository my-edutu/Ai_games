# Testing Strategy

Use native Node unit/contract/property/replay tests, stratified seed campaigns, Playwright browser captures, stream self-tests, performance/load profiles, provider duplicate/reorder/outage scenarios, restore/chaos drills and exact-candidate release validation.

Every behavior begins with a focused failing test. Phase 1 proves config, generation, lifecycle, determinism, random-stream isolation, snapshots and corruption/invariant rejection. Later phases retain all prior regressions and add distributions/tails rather than showcase seeds. Technical, quarantined and test runs are excluded from fair gameplay outcomes.
