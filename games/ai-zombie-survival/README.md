# AI Zombie Survival

Autonomous survivor and zombie simulation with a **new actual 3D WebGL2 vertical slice** plus the existing 2.5D viewer.

## Launch

From repository root:

```bash
npm ci
cd games/ai-zombie-survival
npm run serve
```

Open:

- **3D viewer**: http://127.0.0.1:4177/web/3d.html
- **3D gauntlet progress page**: http://127.0.0.1:4177/web/progress.html
- **Original 2.5D viewer**: http://127.0.0.1:4177/web/index.html
- **Reproducible 3D evidence scene**: http://127.0.0.1:4177/web/3d.html?scenario=large-horde&freeze=1

To verify locally: `npm test`, then `node --check web/gauntlet3d.js`. With Playwright Chromium installed and the server running, run `node tests/gauntlet-browser.mjs`.

## 3D controls

- Drag: rotate 3D camera.
- Scroll: adjust perspective distance.
- **G**: toggle autonomous camera director.
- **H**: hide HUD for clean OBS capture.
- **R**: restart with a new deterministic seed.
- **Space**: pause/resume the authoritative simulation.

## Source of truth

The simulation in `src/` remains the fixed-step authoritative world. `web/gauntlet3d.js` reads that state and draws actual WebGL2 perspective geometry with GPU depth testing. The renderer may not change AI decisions, outcomes or randomness. The existing 2.5D experience remains accessible for fallback.

The procedural 3D pass includes district terrain, roads, buildings, windows, elevated roofs, streetlamps, wrecked vehicles, safe-house landmarks, barricades, loot, civilians, survivor role outfits and three animated infected body archetypes. It adds a broadcast HUD, autonomous camera direction, seeded evidence scenes, frame telemetry, and a live progress dashboard.

## Quality and production honesty

This is **iteration 1** of the Gauntlet, not an AAA-complete build. The major gap versus **Days Gone Remastered** remains character models/rigging, hero environment assets, material quality, physically based lighting, animations, cinematic combat feedback, performance profiling and independent screenshot A/B review.

Browser screenshots are only considered verified when generated by the dedicated Chromium CI workflow. No locally generated illustrations count as runtime captures. Passing source/unit tests is not equivalent to production readiness, OBS capture, 24–72-hour soak or a seven-day canary.

Refer to `GAUNTLET_3D_LEDGER.md`, `VISUAL_ACCEPTANCE_REPORT.md`, and `PRODUCTION_READINESS.md` for gates.
