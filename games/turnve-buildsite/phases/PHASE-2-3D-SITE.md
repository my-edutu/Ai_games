# Phase 2 — 3D Site

## Goal

Create a procedural explorable construction environment that visually communicates workplace context and supports inspection actions.

## Implemented

- React Three Fiber canvas with lighting, fog, shadows, device-pixel-ratio cap.
- Site boundary, branded entrance, office, structural slab/columns, rebar, materials, access blockage, puddle/cable, formwork/open edge.
- Crane motion, truck arrival/release motion, deterministic rain particles.
- Cinematic camera fly-through.
- First-person WASD/arrow movement, mouse pointer-lock look, ground height, site bounds, major-structure collision approximation.
- Proximity inspection with E and clickable guided markers.
- Hazard correction changes physical visuals.
