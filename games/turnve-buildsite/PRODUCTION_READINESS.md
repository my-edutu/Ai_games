# Turnve BuildSite — Production Readiness

## R1 Functional prototype

Core route loads; PPE, inspection, tablet, crisis, artifacts, report, reset work.

## R2 Verified vertical slice

Unit/integration/browser tests execute cleanly; build succeeds; no blocking console errors; reset is repeatable.

## R3 Pitch-ready candidate

Visual/UX review complete, presenter controls reliable, deterministic demo timing, reduced-motion/accessibility basics, documented seven-minute script.

## R4 Pilot-ready candidate

Representative-device performance checks, learner usability testing, construction-domain review, assessment-rubric review, persistence/export privacy review.

## R5 Production ready

Requires deployed-candidate evidence, monitored real-world sessions, security/privacy review, incident ownership, rollback/recovery rehearsal, and employer/institution assessment validation. Source code or CI alone cannot establish R5.
