# Turnve BuildSite — Testing Strategy

## Unit

Task transitions, consequence rules, bounded metrics/trust, artifact scoring, drawing revisions, inspection state, readiness calculation, reset.

## Integration

Hazard → evidence → report; report → stakeholder state; early truck event; unauthorized pour consequences; correct escalation; artifact inconsistency penalty.

## Browser/E2E

Load, Guided Mode, PPE, inspection, tablet, artifact submit, crisis trigger, report, pitch reset.

## Manual pitch verification

Run `npm run dev -- --host`, load `?demo=true`, exercise presenter shortcuts, inspect browser console, complete recommended flow, reset twice, verify no stale state or duplicated listeners.

## Evidence rule

A test is not recorded as passing unless it was executed against the commit/candidate being described.
