# Puzzle Presentation System

The renderer maps existing authoritative primitives to physical forms:

| Puzzle kind | Physical presentation |
| --- | --- |
| `sequence-lock` | four rotating dial blocks and latch rail |
| `symbol-cipher` | three symbol tiles with inspection lighting |
| `shape-order` | ordered physical blocks of distinct heights |
| `tool-dependency` | receptacle plus inserted tool when solved |
| `switch-network` | five lever/switch elements and routing rail |
| `balance-clue` | central balance beam with two pans |
| `direction-pattern` | four directional actuators around a hub |
| `final-vault` | nested rotating vault discs and bolt markers |

Clues are paper-like in-world surfaces; inspected clues reveal additional physical markings. Tools are rendered as tangible handles/instruments. A solved mechanism exposes a dark recess/compartment and a small highlighted reveal, providing environmental progression without fabricating new authoritative objects.

No code, solution string or oracle path is sent to the browser for these visuals.
