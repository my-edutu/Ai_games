# Phase 4 — Safe Audience Interaction

**Target:** R3  
**Initial status:** Not implemented on the feature branch.  
**Exit rule:** Every criterion must have reproducible evidence plus separate specification and quality reviews.

## Acceptance criteria

- [ ] Provider-neutral fixed-choice inputs with schema and stable reason codes.
- [ ] At-most-once processing, logical vote windows and deterministic ties.
- [ ] Paid-eligible weight capped at two; no targeted or terminal effects.
- [ ] Bounded audit/queues and truthful acknowledgement lifecycle.
- [ ] Disabled/provider-outage mode preserves complete autonomous gameplay.

## Review ledger

The phase ledger is updated only after focused tests, affected regressions, evidence capture, specification review and engineering/viewer-experience review. P0/P1 findings block progression.
