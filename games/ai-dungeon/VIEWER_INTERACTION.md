# Viewer and Broadcast Interaction

V1 is a **read-only, unattended spectator experience**. The HTTP server responds to GET requests only and exposes public snapshots, health, static assets and Gauntlet status. It does not accept audience commands or money, and cannot guarantee outcomes on behalf of viewers.

Potential future effects may include voting for exploration modifiers or cosmetic events only after the shared audience gateway verifies identity, moderation, limits, cooldowns, idempotency, fair disclosures, audit logs and deterministic replay inputs. None of those features is approved for public use in this slice.

Legibility: floor progression and AI intent appear on the main scene, with party HP and recaps in the sidebar. Mobile stacks panels underneath the view. A clean OBS feed, stream encoding and provider outage recovery require separate measured work.
