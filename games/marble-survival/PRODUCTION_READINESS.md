# Marble Survival Tournament — Production Readiness

Production readiness is evidence-based. Required gates are deterministic replay and restore, no unresolved critical/important review findings, calibrated campaign distributions, mobile/accessibility captures, audience fairness and audit tests, provider/audio/render degradation, operator authentication, bounded resources, incident/rollback rehearsal, 72-hour candidate soak, and seven-day canary.

Phase 1 establishes deterministic authority and recovery primitives. The release validator introduced in Phase 6 must report temporal soak/canary as pending until genuine elapsed evidence is attached; code completion alone cannot promote the game to unattended production.
