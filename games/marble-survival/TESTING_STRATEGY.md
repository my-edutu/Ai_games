# Marble Survival Tournament — Testing Strategy

The game uses test-first development. Foundation evidence covers config bounds, deterministic unique roster, constructive arena validity, typed validator issues, world/obstacle/bumper/pair contacts, thin-geometry protection, speed/contact bounds, twin runtimes, snapshot restore, corruption rejection, automatic restart, and integrity quarantine.

Later phases add policy legality/diversity, five-round progression, campaign distributions, presentation privacy/layout/audio caps, browser captures, influence duplicates/reorder/reversal/burst/outage, chaos recovery, bounded-resource proxies, security scans, and release validation. Identical seed/event corpora compare balance versions. Bad seeds become regression fixtures.
