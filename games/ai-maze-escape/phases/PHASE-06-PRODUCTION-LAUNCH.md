# Phase 6 — Production Validation and Launch

**Target:** R5 production ready

## Outcome

A frozen candidate operates on a limited real channel for seven days after full simulation, provider, safety, accessibility, performance, recovery, soak and rollback evidence passes.

## Work

Freeze versions and traceability; run final stratified generation/AI/balance campaigns and replay review; validate production-reference capacity, current YouTube/Twitch authentication/reconnect/duplicate/reversal/outage, security/privacy/moderation/assets/accessibility/audio; complete a 72-hour candidate soak with interactions, snapshots, restarts and chaos; rehearse incident, credential, safe-scene, restore/fresh-run and deployment/config/content rollback; run seven-day canary under predeclared promotion/rollback thresholds; obtain independent review.

## Acceptance

- [ ] Every MUST requirement maps to current reproducible evidence.
- [ ] Generator validity, hidden-information integrity, AI/balance/diversity and pathological tails pass.
- [ ] Provider/idempotency/safety/accessibility/performance/resource/recovery gates pass.
- [ ] The 72-hour soak and all runbook/rollback drills pass.
- [ ] Seven-day canary remains within guardrails or rolls back safely.
- [ ] No P0/P1 remains and independent readiness review returns `PASS`.

Material candidate changes re-enter the owning phase and reset affected evidence. Only this exit permits the public R5 label.
