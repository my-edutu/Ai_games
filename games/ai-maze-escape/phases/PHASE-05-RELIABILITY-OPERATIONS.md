# Phase 5 — Persistent Campaigns, Recovery, and Operations

**Target:** R4 infrastructure candidate

## Outcome

Runs, discovered maps, events, records, interactions, and campaign progress are durably auditable; process/provider/output failures recover through verified state and intentional scenes with typed operator controls.

## Scope

Append-only events/snapshots/records/projections, run lease/supervisor, progress/loop/output probes, restore/replay/quarantine/fresh run, bounded queues/history/resources, dashboards/alerts/runbooks, operator dashboard, secrets/privacy/roles/supply chain, configuration/content/deployment compatibility, rollback, 24-hour soak and chaos.

## Acceptance

- [ ] Restore equals uninterrupted truth/belief/route checksums and effects never duplicate.
- [ ] Corrupt/incompatible/divergent state quarantines safely.
- [ ] Stalled exploration and black/frozen/silent output are detected and recovered.
- [ ] Resources stabilize through the engineering soak.
- [ ] Provider/persistence/moderation/component failures follow declared degradation.
- [ ] Operators can disable, restore, fresh-start, restart, rollback and halt through audited controls.
- [ ] Security/privacy/retention and rollback drills pass with no P0/P1.
